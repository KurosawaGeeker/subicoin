# Seller Console Design

版本：v0.1

状态：已定稿，作为控制台落地依据

范围：卖家 Web 的「控制台」选项卡。该页面替换原 `API` 选项卡，用于管理 Seller 节点、接单能力、接入指令、订阅账号、运行时间和节点收益。

## 1. 页面定位

Seller Console 是卖家的供给控制台，不是 API 文档页。

它解决四个问题：

```text
我有几个 Seller 节点
每个节点跑在哪台机器、哪个订阅账号上
每个节点什么时候接单、最多接几个 buyer
每个节点赚了多少钱，以及如何复制该节点的接入指令
```

产品里的列表项定义为「Seller 节点」：

```text
一个 Seller 节点 = 一台运行机器 + 一个订阅账号 + 一套接单规则 + 一份节点收益统计
```

一个平台 seller 账户可以拥有多个 Seller 节点。提现和总资产仍归属平台 seller 账户，节点只用于区分设备、订阅账号、接单规则和收益来源。

## 2. 导航命名

卖家侧主导航：

```text
首页
接入
收益
控制台
```

原 `API` 选项卡改名为 `控制台`。API 文档、命令片段、错误码说明不再作为这个 tab 的主内容；每个 Seller 节点的「接入」按钮负责复制该节点专属接入指令。

## 3. 页面结构

控制台由三层组成：

```text
顶部总览
Seller 节点列表
Seller 节点展开配置
```

### 3.1 顶部总览

| 字段 | 类型 | 展示规则 |
| --- | --- | --- |
| 在线节点 | 只读数字 | 在线 / 全部节点 |
| 当前接入 | 只读数字 | 当前 buyer 数 / 最大 buyer 数 |
| 今日收益 | 只读金额 | 汇总所有节点今日收益 |
| 接单状态 | 只读状态 | 接单中 / 暂停中 / 无可用节点 / 异常 |

顶部总览只做汇总，不承担复杂配置。配置发生在每个 Seller 节点展开区。

### 3.2 Seller 节点列表

默认列表字段：

| 字段 | 类型 | 示例 |
| --- | --- | --- |
| Seller 节点 | 文本 | Home MacBook |
| 运行机器 | 文本 | MacBook Pro |
| 订阅账号 | 文本 | Claude Pro A |
| 接单状态 | 状态 | 接单中 |
| 当前接入 | 数字 | 1 / 2 |
| 运行时间 | 文本 | 每天 09:00-18:00 |
| 今日收益 | 金额 | $12.40 |
| 操作 | 按钮组 | 配置 / 接入 / 暂停 |

列表行可以展开。展开后展示该节点的完整配置项和状态解释。

### 3.3 开始接入

控制台不提供直接把空 Seller 节点塞进列表的「新增」逻辑。列表只展示已经开始接入或已经真实接入过的节点。

控制台提供「开始接入」按钮。

点击后先进入接入选择：

| 字段 | 可选项 | 说明 |
| --- | --- | --- |
| 接入方式 | Codex / Claude Code | 决定该节点运行哪个订阅账号和 upstream provider |
| 最大接入 buyer 数 | 1-3 | 生成节点时写入该节点的接单能力 |

用户确认后，系统生成一个 Seller 节点和该节点专属接入指令，并自动复制命令。只有完成这一步后，该节点才进入 Seller 节点列表。

节点生成默认值：

| 字段 | 默认值 |
| --- | --- |
| 节点名称 | Codex 节点 N / Claude Code 节点 N |
| 运行机器 | 待接入 |
| 订阅账号类型 | 接入选择中的 Codex 或 Claude Code |
| 账号名称 | Codex 订阅 / Claude Code 订阅 |
| 接单模式 | 暂停接新单 |
| 最大接入 buyer 数 | 接入选择中的值 |
| 时间模式 | 仅本次开放 |
| 临时开放时长 | 1 小时 |
| 余额保护模式 | 保底余额 |
| 异常后动作 | 自动暂停接新单 |

节点进入列表后，该行仍保留「接入」按钮，用于重新生成并复制该节点专属接入指令。设备执行命令并连接成功后，状态从 `待接入` 或 `provisioned` 变为 `在线`。

## 4. Seller 节点 Schema

### 4.1 基础信息

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| node_id | 系统 ID | `seller_node_*` | 系统生成 | 否 |
| display_name | 文本输入 | 1-40 字符 | 设备名或新 Seller 节点 | 是 |
| node_status | 状态 | 待接入 / 在线 / 离线 / 异常 / 接单中 / 暂停 / 名额已满 | 系统判断 | 否 |
| unavailable_reason | 状态解释 | 手动暂停 / 不在时间段 / 余额保护触发 / 名额已满 / 机器离线 / 账号异常 / 指令过期 | 系统判断 | 否 |

### 4.2 运行机器

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| machine_name | 文本输入 | 1-40 字符 | 待接入 | 是 |
| machine_type | 下拉或自动识别 | Mac / Windows / Linux / Server / Other | 自动识别 | 是 |
| machine_note | 文本输入 | 0-80 字符 | 空 | 是 |
| last_seen_at | 时间 | 最近心跳时间 | 空 | 否 |

### 4.3 运行账号

运行账号指该节点使用的订阅账号，不向 buyer 暴露。

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| subscription_provider | 下拉 | Codex / Claude / ChatGPT / Cursor / Other | Codex | 是 |
| subscription_label | 文本输入 | 1-40 字符 | Codex 订阅 | 是 |
| account_health | 状态 | 未检测 / 可用 / 额度不足 / 登录失效 / 风控中 | 未检测 | 否 |
| account_visibility | 固定规则 | 仅 seller 自己可见 | 仅 seller | 否 |

### 4.4 接单能力

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| accept_mode | 三段式选择 | 开启接单 / 暂停接新单 / 停止全部接入 | 暂停接新单 | 是 |
| max_buyers | 数字步进器 | 1-10，MVP 先限制 1-3 | 1 | 是 |
| current_buyers | 只读数字 | 0 到 max_buyers | 0 | 否 |
| emergency_stop | 危险操作 | 立即停止全部接入 | 关闭 | 是 |

语义：

```text
开启接单：允许新 buyer 接入，但仍受时间、余额、设备在线和账号状态限制。
暂停接新单：不接新的 buyer，当前连接可以继续跑完。
停止全部接入：不接新 buyer，并断开当前连接，属于紧急操作。
```

### 4.5 运行时间

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| schedule_mode | 单选 | 永久开放 / 每天固定时间 / 仅本次开放 / 手动暂停 | 仅本次开放 | 是 |
| daily_windows | 时间段选择 | 00:00-23:59，可多段 | 空 | 是 |
| repeat_days | 周选择器 | 周一到周日 | 全选 | 是 |
| temporary_duration | 快捷选项 + 自定义 | 1 小时 / 2 小时 / 4 小时 / 8 小时 / 自定义 | 1 小时 | 是 |
| timezone | 下拉 / 自动 | 跟随设备 / 跟随账户 / 指定时区 | 跟随设备 | 是 |

MVP 优先支持：

```text
永久开放
每天固定时间
仅本次开放 N 小时
```

复杂日历、节假日规则和跨时区排班不进第一版。

### 4.6 余额保护

余额保护的目标是避免 Seller 节点影响卖家自己使用订阅账号。

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| balance_guard_mode | 单选 | 保底余额 / 固定可售额度 / 可售比例 | 保底余额 | 是 |
| reserve_balance | 数字输入 | 大于等于 0 | 系统推荐 | 是 |
| sellable_quota | 数字输入 | 大于 0，不能超过可用余额 | 空 | 是 |
| sellable_ratio | 滑杆 | 5%-50%，高级可到 80% | 20% | 是 |
| daily_spend_cap_enabled | 开关 | 开启 / 关闭 | 关闭 | 是 |
| daily_spend_cap | 数字输入 | 大于 0 | 空 | 是 |

推荐默认展示「保底余额」。比例和固定额度作为可选模式。

### 4.7 收益统计

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| today_earning | 只读金额 | 系统计算 | $0 | 否 |
| total_earning | 只读金额 | 系统计算 | $0 | 否 |
| settleable_earning | 只读金额 | 系统计算 | $0 | 否 |
| today_spend | 只读金额 | 系统计算 | $0 | 否 |

收益可以按节点展示，但提现从 seller 总账户发起，不从单个节点发起。

### 4.8 异常处理

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| failure_action | 单选 | 自动暂停接新单 / 自动停止全部接入 / 仅提醒 | 自动暂停接新单 | 是 |
| notification_channels | 多选 | 站内通知 / 邮件 / Telegram / Webhook | 站内通知 | 是 |

MVP 可以只实现站内通知展示，不做真实外部通知。

### 4.9 接入指令

每个 Seller 节点都有独立的「接入」按钮。点击后复制该节点专属接入指令。

| 字段 | 类型 / 控件 | 定义域 | 默认值 | 可编辑 |
| --- | --- | --- | --- | --- |
| setup_status | 状态 | 待生成 / 已生成 / 已复制 / 指令已过期 / 已接入 | 待生成 | 否 |
| setup_command | 复制按钮 | 节点专属一键接入命令 | 系统生成 | 否 |
| setup_token_expires_at | 时间 | 30 分钟 / 24 小时 / 已过期 | 24 小时 | 否 |
| last_connected_at | 时间 | 最近接入时间 | 空 | 否 |
| disconnect_action | 危险操作 | 解绑设备，保留收益记录 | 空 | 是 |

命令形态示例：

```bash
curl -fsSL https://subi.network/install.sh | sh -s -- \
  --node seller_node_xxx \
  --token setup_token_xxx
```

规则：

```text
接入指令必须绑定具体 Seller 节点。
不同节点不能共用同一条接入指令。
接入指令必须短期有效，过期后可重新生成。
接入指令不包含订阅账号密码。
订阅账号登录态在 seller 设备本地完成。
```

## 5. 状态优先级

Seller 节点是否可接单按以下优先级判断：

```text
停止全部接入
手动暂停接新单
机器离线或异常
订阅账号异常
余额保护触发
不在运行时间段
当前接入数达到上限
可以接单
```

页面必须解释不可接单原因，不能只显示「离线」或「不可用」。

## 6. 不做的事

第一版不做：

```text
Seller 挑订单
Seller 选择任务类型
Seller 手动报价
Buyer 选择具体 Seller
复杂日历排班
完整外部通知系统
节点级提现
```

Seller 能控制的是自己的供给边界，不是订单分发。平台负责路由、计量和结算。

## 7. 前端落地要求

第一版代码落地可以先用前端状态和现有节点接口组合完成，不要求一次性补齐所有后端持久化能力。

必须落地：

```text
API tab 改名为控制台
控制台页展示 Seller 节点列表
支持开始接入，并在接入前选择 Codex 或 Claude Code
只有生成接入指令或真实接入过的节点才进入列表
每个 Seller 节点可展开配置
每个 Seller 节点有接入按钮
接入按钮复制该节点专属接入命令
字段定义域按本文档展示
状态解释按本文档展示
```

可以后续接真实后端：

```text
节点配置持久化
时间段规则执行
余额保护真实触发
节点级收益聚合
setup token 过期重生成
外部通知
```
