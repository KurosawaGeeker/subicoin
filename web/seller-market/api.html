给买家一个可替换的便宜 token endpoint。

买家继续使用 OpenAI-compatible 客户端原本读取的环境变量名。只需要把值换成 Subi Gateway URL 和 Subi buyer key。

买家配置

Codex CLI

export OPENAI_BASE_URL="https://api.subi.xyz/v1"
export OPENAI_API_KEY="sk-subi_xxx"

codex \
  -c 'model_provider="subi"' \
  -c 'model_providers.subi.name="Subi"' \
  -c "model_providers.subi.base_url=\"${OPENAI_BASE_URL}\"" \
  -c 'model_providers.subi.env_key="OPENAI_API_KEY"' \
  -c 'model_providers.subi.wire_api="responses"'
卖家节点

Provider 节点

export SUBI_GATEWAY_WS_URL="wss://api.subi.xyz/api/v1/subi/seller/agent/ws"
export SUBI_SELLER_NODE_TOKEN="seller_node_xxx"
export SUBI_NODE_ID="seller-001"
export SELLER_UPSTREAM_MODE="codex-app-server"

./seller-agent

买家和卖家都能看懂的错误

401 API key 或 seller token 无效
402 后续计费流程中代表买家余额不足
429 并发限制已达到
503 当前没有可用卖家节点
504 卖家节点或本地 upstream 超时
529 Provider 临时过载
